Firebase Firestoreのセキュリティルール設定が必要です

データアクセスの権限不足エラー (`Missing or insufficient permissions`) が発生しました。
Firebase Console で Firestore Database のルールを以下のように変更してください： 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
Firebase Console を開く

作物の成長を記録し、
最適なお世話をサポート

PlantCheckは、野菜やハーブ、観葉植物の植え付けから収穫・開花までの成長日記をオンラインで安全に管理・保存できるアプリです。

個別に成長管理

トマト、イチゴ、多肉植物など、種類ごとに分けて記録をストックできます。

水やり＆肥料ログ

いつ水やりや追肥を行ったかをタイムライン形式でわかりやすく視覚化。

写真つきメモ

日々の草丈や葉の色の変化を写真リンクと一緒に記録可能です。
